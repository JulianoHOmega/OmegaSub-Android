Legendas PT-BR - Linux x86_64

1. Extraia o arquivo .tar.gz (nao execute de dentro do compactador).
2. Abra um terminal na pasta Legendas-PTBR extraida.
3. Execute: chmod +x iniciar.sh Legendas-PTBR
4. Execute: ./iniciar.sh

O Python nao precisa estar instalado. O sistema ainda precisa das bibliotecas graficas compativeis com Qt.
Se ocorrer "failed to load module" ou erro de Qt, execute ./iniciar.sh pelo terminal e envie o erro completo.
Este pacote foi compilado no Ubuntu 22.04 x86_64; outras distribuicoes precisam de teste.
